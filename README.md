# M-sica-

Relatório de Aprendizagem

1. Introdução

Neste trabalho, desenvolvi um site sobre música para colocar em prática o que aprendemos nas aulas de Desenvolvimento Web I. Também tive o objetivo de aprender a publicar um site na internet usando o GitHub Pages.

2. Desenvolvimento do site

Primeiro, criei o arquivo "index.html", onde coloquei os textos e organizei as partes do site. Depois, criei o arquivo "style.css", que usei para escolher as cores, os tamanhos das letras, os espaçamentos e a aparência da página.

Escolhi o tema música porque é um assunto que gosto muito e pode ser usada de diversas formas no dia a dia.

3. Ferramentas utilizadas

Utilizei HTML para criar a estrutura do site e CSS para personalizar sua aparência. Também utilizei o GitHub para organizar e guardar os arquivos do projeto.

O GitHub Pages foi utilizado para publicar o site na internet, permitindo que outras pessoas possam acessá-lo por meio de um link.

4. Conclusão

Concluí que esse trabalho foi importante para colocar em prática o que aprendemos em aula e conhecer novas ferramentas. Aprendi que criar um site não envolve apenas escrever o código, mas também organizar os arquivos e publicar o resultado na internet. Tive bastante dificuldade com a parte do github e o github Pages, mas o trabalho está entregue.
